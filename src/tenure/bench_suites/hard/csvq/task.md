CSV 텍스트에 SQL 비슷한 질의를 실행하는 Python 패키지 `csvq` 를 만든다.

- 패키지는 작업 폴더 최상위의 `csvq/` 에 둔다 (src 레이아웃을 쓰지 말 것). 표준 라이브러리만 쓴다(`csv` 모듈은 써도 된다).
- 질의를 토큰으로 나누는 부분, 구문 분석, 실행은 서로 다른 모듈로 나눈다.
- 아래 이름과 동작을 정확히 지킨다. 다른 사람이 이 인터페이스로 테스트한다. 규칙이 서로 부딪혀 보이면 아래에 적힌 대로 한다.

## 인터페이스

- `csvq.query(csv_text: str, q: str) -> list[dict[str, str]]`
- `csvq.QueryError` : `ValueError` 의 하위 클래스. 질의나 데이터가 잘못되면 이것을 낸다.

## 데이터

- 첫 줄이 머리글(열 이름). 따옴표·쉼표·줄바꿈이 든 필드는 표준 CSV 규칙(`csv` 모듈 기본값)을 따른다.
- 머리글이 없거나 열 이름이 겹치면 `QueryError`. 어떤 행의 필드가 머리글보다 많으면 `QueryError`, 적으면 모자란 필드는 빈 값.
- **빈 문자열은 NULL** 이다.
- 열의 타입: 그 열의 빈 값이 아닌 값이 **모두** 정규식 `-?(0|[1-9][0-9]*)(\.[0-9]+)?` 에 맞으면 숫자 열, 하나라도 아니면 텍스트 열. 그래서 `007` 이 하나라도 있으면 텍스트 열이다. 값이 모두 빈 열은 숫자·문자열 어느 쪽과도 비교할 수 있다(결과는 항상 UNKNOWN).

## 질의 문법

```
SELECT <열 목록 | *> [WHERE <조건>] [ORDER BY <열> [ASC|DESC] {, <열> [ASC|DESC]}] [LIMIT <정수>]
```

- 절의 순서는 위와 같아야 한다. 키워드(`SELECT WHERE ORDER BY ASC DESC LIMIT AND OR NOT`)는 대소문자를 가리지 않고, 열 이름은 가린다.
- 열 이름: `[A-Za-z_][A-Za-z0-9_]*`, 또는 큰따옴표로 감싼 이름(`"unit price"`, 안의 `"` 는 `""`). 키워드와 같은 이름은 따옴표로 감싸야 한다.
- `*` 는 머리글 순서대로 모든 열.
- 조건: `<열> <연산자> <값>`(값은 항상 오른쪽). 연산자 `= != <> < <= > >=`. 값은 숫자 `-?[0-9]+(\.[0-9]+)?` 또는 작은따옴표 문자열(안의 `'` 는 `''`). `NOT`, `AND`, `OR`, 괄호. 우선순위는 `NOT` > `AND` > `OR`.
- `LIMIT` 은 0 이상의 정수. 그 외 문법 오류, 없는 열 이름은 모두 `QueryError`.

## 의미

- 숫자 열은 숫자로(`1.0` 과 `1` 은 같다), 텍스트 열은 유니코드 코드 포인트 순서로(대소문자 구분) 비교한다.
- 숫자 열을 문자열 값과, 텍스트 열을 숫자 값과 비교하면 `QueryError`.
- **SQL 의 3값 논리**: NULL 과의 비교는 참도 거짓도 아닌 UNKNOWN 이다(`!=` 도 마찬가지). `NOT UNKNOWN` 은 UNKNOWN, `FALSE AND UNKNOWN` 은 FALSE, `TRUE OR UNKNOWN` 은 TRUE. 조건이 TRUE 인 행만 결과에 들어간다.
- `ORDER BY`: 숫자 열은 숫자 순, 텍스트 열은 코드 포인트 순. **NULL 은 ASC 든 DESC 든 항상 맨 뒤.** 키가 같으면 원래 행 순서를 유지한다. SELECT 에 없는 열로도 정렬할 수 있다.
- 결과: 행마다 SELECT 한 열 이름 → **입력 텍스트 그대로의 값**(숫자 열이라도 `"007"`, `"1.50"` 을 바꾸지 않는다. NULL 은 `""`). dict 의 키 순서는 SELECT 순서.
