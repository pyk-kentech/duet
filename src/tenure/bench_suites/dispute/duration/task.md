기간 문자열을 다루는 Python 패키지 `duration` 을 만든다. 설정 파일의 `timeout = "1h30m"` 같은 값을 읽고 쓰는 데 쓴다.

- 패키지는 작업 폴더 최상위의 `duration/` 에 둔다 (src 레이아웃을 쓰지 말 것). 표준 라이브러리만 쓴다.
- 설정 파일을 사람이 직접 고치므로, 오타를 조용히 받아들이지 않고 **엄격하게** 거부하는 것이 목적이다. 아래 문법 밖의 입력은 모두 오류다.
- 아래 이름과 동작을 정확히 지킨다. 다른 사람이 이 인터페이스로 테스트한다.

## `duration.parse(text) -> int`

- 초 단위 정수를 돌려준다. 예: `"1h30m"` → 5400, `"2d"` → 172800, `"45s"` → 45, `"0s"` → 0, `"1d2h3m4s"` → 93784.
- 문법: 단위 `d`(86400초), `h`(3600), `m`(60), `s`(1) 를 **이 순서로**, 각 단위는 최대 한 번, 하나 이상. 각 단위 앞에는 0 이상의 10진 정수(ASCII 숫자 하나 이상, 앞의 0 허용: `"05m"` → 300).
- 다음은 모두 `ValueError`: 빈 문자열, 공백이 섞인 것(`"1h 30m"`, `" 1h"`), 대문자(`"1H"`), 순서가 틀린 것(`"30m1h"`), 같은 단위 반복(`"1h1h"`), 단위 없는 숫자(`"90"`), 소수(`"1.5h"`), 부호(`"-1h"`, `"+1h"`), 모르는 단위(`"1w"`, `"1ms"`), ASCII 가 아닌 숫자(`"١h"`).
- `text` 가 `str` 이 아니면 `TypeError`.

## `duration.format(seconds) -> str`

- `parse` 의 반대. 가장 큰 단위부터, 0 인 단위는 생략한다. 예: 5400 → `"1h30m"`, 93784 → `"1d2h3m4s"`, 86400 → `"1d"`, 0 → `"0s"`.
- `seconds` 는 0 이상의 `int`. 음수면 `ValueError`, `int` 가 아니면(`float`, `bool`, `str` 포함) `TypeError`.
- 모든 0 이상 정수 `n` 에 대해 `parse(format(n)) == n`.
