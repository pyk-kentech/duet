작업 폴더 최상위에 파이썬 패키지 `mdlite`(표준 라이브러리만, Python 3.11 이상)를 만든다. 마크다운의 한 부분집합을 HTML 로 바꾸는 렌더러다. 패키지는 작업 폴더 바로 아래 `mdlite/` 에 둔다(src 레이아웃 아님). 마크다운 라이브러리(`markdown`, `mistune`, `commonmark`, `markdown-it-py` 등)는 쓰지 않고 직접 구현한다. 아래의 이름·시그니처·출력 형식은 그대로 지킨다. 다른 사람이 이 인터페이스로 테스트한다. 테스트도 함께 작성한다.

## 인터페이스

- `mdlite.render(text: str) -> str` : 마크다운 텍스트를 HTML 문자열로 바꾼다. 어떤 입력도 유효한 마크다운이므로 예외를 내지 않는다.

## 기준

- 아래 "지원 범위" 안의 입력에 대해 **출력은 CommonMark 0.31.2 명세의 참조 HTML 과 글자 하나까지 같아야 한다.** 줄바꿈·공백 배치까지 명세 예제에 적힌 HTML 과 같다(참조 구현 commonmark.js 0.31.2 의 기본 출력과 같다).
- 아래 규칙은 명세를 요약한 것이다. 요약에 없는 세부는 명세를 따른다. 링크 주소의 퍼센트 인코딩처럼 명세가 정하지 않은 부분은 아래에 적은 대로 한다.

## 입력에 대한 약속 (테스트 입력은 이것을 지킨다)

- 줄 끝은 `\n` 만 쓴다. 탭(`\t`), `\r`, NUL 문자는 나오지 않는다. 마지막 줄은 `\n` 으로 끝날 수도, 아닐 수도 있다.
- **raw HTML 은 지원하지 않는다.** 테스트 입력에는 CommonMark 가 HTML 블록이나 인라인 HTML 로 해석할 부분이 없다. 그러니 자동 링크가 아닌 `<` 는 언제나 글자 그대로다(출력 `&lt;`).
- **엔티티·숫자 문자 참조는 지원하지 않는다.** 테스트 입력에는 `&copy;`, `&#35;`, `&#x22;` 처럼 참조를 이루는 `&` 가 없다. `&` 는 언제나 글자 그대로다(출력 `&amp;`).
- 확장 문법(표, 취소선, 각주, 작업 목록, 스마트 따옴표 등)은 없다. 그렇게 보이는 글자도 CommonMark 대로 처리한다.
- 들여쓰기는 모두 공백 칸 수로 센다.

## 출력 형식

- 텍스트·코드·속성값에서 `&` `<` `>` `"` 는 `&amp;` `&lt;` `&gt;` `&quot;` 로 바꾼다. 그 밖의 문자(작은따옴표, 비 ASCII 포함)는 그대로 쓴다.
- 블록: 문단 `<p>…</p>`, 제목 `<h1>…</h1>` ~ `<h6>…</h6>`, 구분선 `<hr />`, 코드 블록 `<pre><code>…</code></pre>`(정보 문자열이 있으면 `<code class="language-첫단어">`), 인용 `<blockquote>…</blockquote>`, 목록 `<ul>` / `<ol>`(시작 번호가 1 이 아니면 `<ol start="N">`), 항목 `<li>…</li>`.
- 인라인: `<em>`, `<strong>`, `<code>`, `<a href="…">`(제목이 있으면 `<a href="…" title="…">`), `<img src="…" alt="…" />`(제목이 있으면 `<img src="…" alt="…" title="…" />`), 강제 줄바꿈 `<br />`, 부드러운 줄바꿈은 `\n` 한 글자.
- 줄바꿈 배치. "필요하면 줄바꿈" 은 지금까지의 출력이 비어 있지 않고 `\n` 으로 끝나지 않을 때만 `\n` 하나를 쓴다는 뜻이다.
  - 문단·제목·코드 블록·구분선: 여는 태그 앞과 닫는 태그(구분선은 `<hr />`) 뒤에 필요하면 줄바꿈.
  - 인용·목록(`ul`, `ol`): 여는 태그의 앞과 뒤, 닫는 태그의 앞과 뒤에 필요하면 줄바꿈.
  - 항목: `<li>` 앞뒤에는 아무것도 넣지 않고, `</li>` 뒤에만 필요하면 줄바꿈.
  - 촘촘한(tight) 목록에서 항목에 바로 담긴 문단은 `<p>`·`</p>` 와 그 앞뒤 줄바꿈 없이 내용만 쓴다.
  - 강제 줄바꿈: `<br />` 다음에 필요하면 줄바꿈.
  - 코드 블록 내용은 HTML 이스케이프만 해서 그대로 쓴다(내용이 있으면 `\n` 으로 끝난다).
- 그래서 빈 문서의 출력은 `""` 이고, 그 밖에는 `\n` 으로 끝난다.
- 예 (파이썬 문자열 표기):

```
"- a\n- b\n"            -> "<ul>\n<li>a</li>\n<li>b</li>\n</ul>\n"
"- a\n\n- b\n"          -> "<ul>\n<li>\n<p>a</p>\n</li>\n<li>\n<p>b</p>\n</li>\n</ul>\n"
"- a\n  > b\n"          -> "<ul>\n<li>a\n<blockquote>\n<p>b</p>\n</blockquote>\n</li>\n</ul>\n"
"- a\n  - b\n"          -> "<ul>\n<li>a\n<ul>\n<li>b</li>\n</ul>\n</li>\n</ul>\n"
"-\n"                   -> "<ul>\n<li></li>\n</ul>\n"
">\n"                   -> "<blockquote>\n</blockquote>\n"
"3. x\n"                -> "<ol start=\"3\">\n<li>x</li>\n</ol>\n"
"```py\nx < y\n```\n"   -> "<pre><code class=\"language-py\">x &lt; y\n</code></pre>\n"
"a  \nb\n"              -> "<p>a<br />\nb</p>\n"
"# Title #\n\nSome *em* and **strong** text.\n"
                        -> "<h1>Title</h1>\n<p>Some <em>em</em> and <strong>strong</strong> text.</p>\n"
"[t](</a b> \"T\")\n"   -> "<p><a href=\"/a%20b\" title=\"T\">t</a></p>\n"
"![a *b*](/i.png)\n"    -> "<p><img src=\"/i.png\" alt=\"a b\" /></p>\n"
```

## 지원 범위 — 블록

### 해석 방식

- 두 단계로 해석한다. 먼저 줄 단위로 블록 구조를 만들고, 그다음 문단·제목의 내용을 인라인으로 해석한다. 링크 참조 정의는 블록 단계에서 문서 전체에서 모은 뒤 인라인 단계에서 쓴다(정의가 사용보다 뒤에 있어도 된다).
- 컨테이너 블록(인용, 목록 항목)은 다른 블록을 담고, 리프 블록(문단, 제목, 코드 블록, 구분선)은 글을 담는다. 각 줄마다 열린 컨테이너를 바깥부터 차례로 "이 줄에서도 이어지는가" 확인하고(인용은 `>` 표시, 항목은 충분한 들여쓰기 또는 빈 줄), 남은 부분에서 새 블록의 시작을 찾고, 그래도 남은 글은 문단의 줄이 된다. 이어지지 않은 컨테이너와 그 안의 블록은 닫힌다.
- 컨테이너 안에서는 컨테이너 표시가 차지한 칸을 뺀 나머지에서 들여쓰기를 센다.
- **게으른 이어짐(laziness)**: 열린 문단이 있을 때, 이번 줄이 컨테이너 표시(`>`, 항목 들여쓰기)를 일부 빠뜨렸더라도 남은 내용이 새 블록의 시작이 아니라 문단의 이어짐이면 그 문단에 이어 붙인다. 문단 이어짐만 게으를 수 있다(목록 항목·구분선·코드 펜스·제목 등으로 시작하는 줄은 그 블록이 된다). setext 제목 밑줄도 게으를 수 없다.

### 문단

- 다른 블록으로 해석되지 않는 비어 있지 않은 줄들. 빈 줄이 문단을 끝낸다.
- 각 줄의 앞 공백은 지운다(이어지는 줄은 4칸 이상 들여써도 문단의 일부다). 문단 내용 전체의 앞뒤 공백도 지운다.

### 구분선

- 들여쓰기 0~3칸, 같은 문자(`*`, `-`, `_` 중 하나) 3개 이상. 사이와 끝에 공백이 있어도 되고, 다른 문자가 있으면 안 된다. 문단을 끊을 수 있다.
- 목록 항목으로도 볼 수 있는 줄(`* * *`, `- - -`)은 구분선이다. 단, 문단 바로 다음 줄이 내부 공백 없는 `-` 들이면 setext 제목 밑줄이 우선이다.

### ATX 제목

- 들여쓰기 0~3칸, `#` 1~6개, 그 뒤에 공백 또는 줄 끝. `#` 이 7개 이상이거나 `#` 바로 뒤에 글자가 붙으면 제목이 아니다.
- 내용의 앞뒤 공백은 지운다. 끝의 닫는 열(공백 뒤에 오는 `#` 들과 그 뒤의 공백)은 버린다. 내용이 `#` 들뿐이면 빈 제목이다. 공백 없이 붙은 `#`(`# foo#`)이나 `\#` 로 이스케이프된 `#` 는 내용이다.
- 빈 제목도 된다(`#` → `<h1></h1>`). 문단을 끊을 수 있다.

### setext 제목

- 문단(한 줄 이상) 바로 다음 줄이 들여쓰기 0~3칸의 `=` 들(→ `h1`) 또는 `-` 들(→ `h2`)이고 그 뒤에 공백만 있으면, 그 문단이 제목이 된다. 밑줄 문자는 1개 이상, 사이에 공백은 안 된다. 내용은 여러 줄일 수 있다(줄 사이는 문단과 같은 줄바꿈 규칙).
- 밑줄은 게으른 이어짐이 될 수 없다: `> foo\n---` 는 인용 다음 구분선이다. 4칸 이상 들여쓴 밑줄은 문단의 이어짐이다.

### 들여쓴 코드 블록

- 4칸 이상 들여쓴 비어 있지 않은 줄로 시작한다. **문단을 끊을 수 없다**(열린 문단이 있으면 그 문단의 이어짐이다).
- 각 줄에서 4칸을 뗀다. 사이의 빈 줄은 내용에 들어간다(빈 줄의 4칸을 넘는 공백은 남는다). 끝의 빈 줄들은 버린다. 내용은 `\n` 으로 끝난다.

### 펜스 코드 블록

- 들여쓰기 0~3칸, 백틱(`` ` ``) 3개 이상 또는 물결(`~`) 3개 이상으로 연다. 백틱 펜스의 정보 문자열에 백틱이 있으면 펜스가 아니다.
- 정보 문자열: 펜스 뒤 나머지의 앞뒤 공백을 지우고 백슬래시 이스케이프를 푼 것. 비어 있지 않으면 첫 단어(공백 전까지)에 `language-` 를 붙여 class 로 쓴다.
- 닫는 펜스: 들여쓰기 0~3칸(여는 펜스의 들여쓰기와 무관), 여는 펜스와 같은 문자, 길이가 여는 펜스 이상, 뒤에는 공백만.
- 내용의 각 줄에서는 여는 펜스의 들여쓰기 칸 수만큼까지 앞 공백을 뗀다.
- 닫히지 않으면 그 펜스를 담은 컨테이너(없으면 문서)가 끝날 때까지가 내용이다.
- 문단을 끊을 수 있다. 내용은 인라인으로 해석하지 않는다. 빈 줄도 내용이다.

### 인용

- 들여쓰기 0~3칸의 `>` 가 표시이고, 바로 뒤 공백 하나도 표시에 들어간다. 나머지를 블록으로 해석한다.
- `>` 표시가 있는 줄(과 게으른 문단 이어짐)이 이어지는 동안 인용이 이어진다. `>` 없는 빈 줄은 인용을 끝낸다. `>` 만 있는 줄은 인용 안의 빈 줄이다.
- 문단을 끊을 수 있다.

### 목록 항목과 목록

- 항목 표시: 불릿 `-` `+` `*`, 또는 번호(아라비아 숫자 1~9자리)와 `.` 또는 `)`. 표시 앞 들여쓰기는 0~3칸, 표시 바로 뒤에는 공백 1칸 이상 또는 줄 끝이 와야 한다.
- 내용 시작 칸 W = 표시 앞 들여쓰기 + 표시 너비 + N. N 은 표시 뒤 공백 수(1~4). 표시 뒤 공백이 5칸 이상이면 N = 1(내용은 들여쓴 코드로 시작한다). 표시 뒤가 비어 있으면 N = 1.
- 항목의 다음 줄은 W 칸 이상 들여쓰였으면 항목 안이다(W 칸을 떼고 해석). 빈 줄도 항목 안이다. 그 밖의 줄은 항목을 끝낸다(게으른 문단 이어짐은 예외).
- 표시 뒤가 비어 있는 항목(빈 줄로 시작)은 다음 줄도 빈 줄이면 빈 항목으로 끝난다. 항목은 빈 줄 하나까지만으로 시작할 수 있다.
- 문단을 끊으려면 불릿이거나 번호가 1 이어야 하고, 항목 내용이 비어 있지 않아야 한다.
- 이어지는 항목들이 같은 종류면 한 목록이다: 불릿은 문자가 같아야 하고, 번호는 구분자(`.` 또는 `)`)가 같아야 한다. 다르면 새 목록이 시작된다. 번호 목록의 시작 번호는 첫 항목의 번호다(앞의 0 은 무시: `003.` → 3).
- 중첩은 들여쓰기로 정해진다. 항목의 W 칸 이상 들여쓴 표시는 그 항목 안의 새 목록이다. 예: `10. a\n    - b` 는 중첩(W = 4), `10. a\n   - b` 는 중첩이 아니다.
- **촘촘함(tight)/느슨함(loose)**: 목록은 (a) 한 항목이 끝난 뒤 다음 항목이 시작되기 전에 빈 줄이 있거나, (b) 어떤 항목이 직접 담은 이웃한 두 블록 사이에 빈 줄이 있으면 느슨하고, 아니면 촘촘하다. 항목이 담은 블록의 안쪽(하위 목록의 항목 사이, 코드 블록·인용 안)에 있는 빈 줄과 목록 맨 끝 뒤의 빈 줄은 이 목록에 영향이 없다. 느슨한 목록은 항목 안 문단을 `<p>` 로 싸고, 촘촘한 목록은 싸지 않는다.

### 링크 참조 정의

- 문단의 맨 앞에서만 인식한다(그래서 문단을 끊을 수 없다). 여러 개가 이어질 수 있다. 정의는 출력되지 않고, 정의만으로 된 문단은 사라진다. 정의 뒤에 남은 줄들은 보통 문단이 된다.
- 형식: 들여쓰기 0~3칸, 링크 라벨 `[…]`, `:`, 공백(줄바꿈 최대 1개 포함), 링크 주소, 그리고 선택으로 공백(줄바꿈 최대 1개 포함) 뒤에 링크 제목. 그 뒤로 줄 끝까지 공백만 있어야 한다.
  - 제목 뒤 같은 줄에 다른 글자가 있을 때: 제목이 주소와 다른 줄에서 시작했으면 제목 없는 정의이고 제목 줄부터는 문단이다. 제목이 주소와 같은 줄이면 정의가 아니다.
  - 주소가 없으면 정의가 아니다. 제목 안에 빈 줄은 올 수 없다.
- 링크 주소·제목의 형식은 인라인 링크와 같다(아래).
- 라벨: 이스케이프되지 않은 `[` `]` 를 담을 수 없고, 공백 아닌 글자가 있어야 하며, 999자 이하.
- 라벨 비교: 앞뒤 공백을 지우고, 이어진 공백·줄바꿈을 공백 하나로 바꾸고, 유니코드 대소문자 접기(case fold, 파이썬 `str.casefold()`)를 한 결과가 같으면 같은 라벨이다. 백슬래시 이스케이프는 풀지 않고 비교한다(`[foo\!]` 와 `[foo!]` 는 다르다).
- 같은 라벨을 여러 번 정의하면 문서에서 처음 나온 것이 이긴다. 인용·목록 안의 정의도 문서 전체에서 쓰인다.

## 지원 범위 — 인라인

왼쪽에서 오른쪽으로 해석한다. 코드 스팬과 자동 링크가 링크 괄호·강조보다 먼저 묶이고, 링크 괄호가 강조보다 먼저 묶인다(예: `*[foo*](/u)` 의 첫 `*` 는 글자).

### 백슬래시 이스케이프

- ASCII 구두점 `` !"#$%&'()*+,-./:;<=>?@[\]^_`{|}~ `` 앞의 `\` 는 그 문자를 특별한 뜻 없는 글자로 만든다(`\` 는 사라진다). 그 밖의 문자 앞의 `\` 는 글자 `\` 다.
- 줄 끝의 `\` 는 강제 줄바꿈이다. 문단·제목 내용의 맨 끝에 있으면 글자 `\` 다.
- 코드 스팬·코드 블록·자동 링크 안에서는 동작하지 않는다. 링크 주소·제목·라벨(비교는 위 규칙)·정보 문자열에서는 동작한다.

### 코드 스팬

- 백틱 n개의 열이 열고, 길이가 정확히 n 인 다음 백틱 열이 닫는다. 닫는 열이 없으면 여는 백틱들은 글자 그대로다.
- 내용: 줄바꿈을 공백으로 바꾼다. 그 결과가 공백으로 시작하고 공백으로 끝나며 공백만으로 되어 있지 않으면 앞뒤에서 공백을 하나씩 뗀다. 그 밖의 공백은 그대로 둔다.

### 강조 (`*`, `_`)

- 구분자 열: 이스케이프되지 않은 같은 문자(`*` 또는 `_`)가 이어진 최대 길이의 열.
- 열의 앞 글자·뒤 글자를 본다. 문단 내용의 처음·끝과 줄바꿈은 공백으로 친다.
  - 공백 = 유니코드 Zs 범주 문자, 탭, 줄바꿈, 폼피드, CR.
  - 구두점 = ASCII 구두점, 또는 유니코드 P(구두점)·S(기호) 범주 문자. (그래서 `€`, `£` 도 구두점이다.)
- 왼쪽 측면(left-flanking): 뒤 글자가 공백이 아니고, (뒤 글자가 구두점이 아니거나 앞 글자가 공백·구두점).
- 오른쪽 측면(right-flanking): 앞 글자가 공백이 아니고, (앞 글자가 구두점이 아니거나 뒤 글자가 공백·구두점).
- `*` 열: 왼쪽 측면이면 열 수 있고, 오른쪽 측면이면 닫을 수 있다.
- `_` 열: 왼쪽 측면이고 (오른쪽 측면이 아니거나 앞 글자가 구두점)이면 열 수 있다. 오른쪽 측면이고 (왼쪽 측면이 아니거나 뒤 글자가 구두점)이면 닫을 수 있다. 그래서 `snake_case_word` 의 `_` 는 강조가 아니다.
- 짝 맞추기: 구분자 열을 나온 순서대로 스택에 둔다. 앞에서부터 닫을 수 있는 열(closer)을 만날 때마다, 그보다 앞에서 가장 가까운, 같은 문자이고 열 수 있는 열(opener)을 찾는다.
  - **3의 배수 규칙**: opener 와 closer 중 하나라도 열기와 닫기가 둘 다 가능하면, 두 열의 원래 길이의 합이 3의 배수일 때 짝이 될 수 없다. 단 두 길이가 모두 3의 배수이면 짝이 될 수 있다.
  - 짝을 찾으면 opener 와 closer 의 남은 길이가 둘 다 2 이상이면 2개를 써서 `<strong>`, 아니면 1개를 써서 `<em>` 을 만든다. 둘 사이의 내용이 그 요소의 내용이고, 사이에 있던 구분자 열은 더 이상 짝이 될 수 없다(글자로 남는다). 다 쓴 열은 없어지고, closer 에 남은 구분자가 있으면 그 closer 로 다시 찾는다. 쓰는 구분자는 opener 쪽에서는 오른쪽 끝, closer 쪽에서는 왼쪽 끝이다.
  - opener 를 못 찾은 closer 는 넘어간다(열 수도 있는 열이면 뒤의 closer 를 위한 opener 후보로 남는다). 끝까지 짝이 없는 구분자는 글자 그대로다.
- 링크·이미지가 만들어질 때, 그 텍스트 안의 구분자는 그 안에서만 짝을 맞춘다(링크 경계를 넘어 짝이 되지 않는다).

### 링크

- 인라인 링크 `[텍스트](주소 "제목")`.
  - 링크 텍스트: 대괄호 안. 이스케이프되지 않은 대괄호는 짝이 맞아야 한다. 강조·코드·이미지를 담을 수 있지만 **링크는 담을 수 없다**: 안쪽에서 링크가 만들어지면 그것을 담은 바깥 `[` 는 글자가 된다.
  - `]` 바로 뒤에 `(` 가 와야 한다(사이에 공백 불가). 괄호 안은 공백(줄바꿈 최대 1개 포함), 주소, 공백, 선택 제목, 공백, `)` 순서다.
  - 주소: `<…>` 꼴(줄바꿈이나 이스케이프되지 않은 `<` `>` 는 불가, 공백은 가능, 빈 `<>` 가능), 또는 `<` 로 시작하지 않고 공백·제어 문자가 없으며 이스케이프되지 않은 괄호가 짝이 맞는 글자열(괄호 안이 비어 있으면 빈 주소: `[a]()`).
  - 제목: `"…"`, `'…'`, `(…)`. 안에서 같은 따옴표(또는 괄호)는 이스케이프해야 한다. 주소와 제목 사이에는 공백이 있어야 한다.
  - 형식이 맞지 않으면 인라인 링크가 아니다(아래 참조 링크로 볼 수 있으면 그렇게 본다).
- 참조 링크: 전체 `[텍스트][라벨]`, 축약 `[라벨][]`, 단축 `[라벨]`. 라벨이 정의와 맞을 때만 링크다. `]` 와 `[` 사이에 공백은 안 된다. 축약·단축은 첫 대괄호의 내용이 라벨이자 링크 텍스트다.
  - 인라인 링크 형식이 먼저다. 그것이 실패하면 참조로 본다(`[foo](not a link)` 는 `[foo]` 가 정의되어 있으면 단축 참조 링크 뒤에 글자 `(not a link)`).
  - 단축 참조 뒤에 `[]` 나 다른 링크 라벨이 오면 단축 참조가 아니다. 그래서 `[foo][bar]` 에서 `bar` 가 정의되지 않았으면 `foo` 가 정의되어 있어도 전체가 글자다.
- 이미지: `!` 바로 뒤에 링크 문법(인라인·참조 모두). 이미지 설명은 링크도 담을 수 있다. `alt` 는 설명의 **순수 텍스트**다(강조·코드·링크·이미지의 태그를 빼고 글자만 이어 붙인 것).

### 자동 링크

- `<스킴:…>`: 스킴은 영문자로 시작하고 영문자·숫자·`+`·`.`·`-` 로 된 2~32자. 그 뒤 `:` 다음에 공백·`<`·`>`·제어 문자가 없는 글자들. href 는 그 URI(아래 인코딩), 링크 텍스트는 그대로.
- `<메일주소>`: 로컬 부분 `[a-zA-Z0-9.!#$%&'*+/=?^_`{|}~-]+`, `@`, 도메인(영문자·숫자로 시작하고 끝나는 63자 이하의 영문자·숫자·`-` 라벨들을 `.` 로 이은 것). href 는 `mailto:` + 주소, 텍스트는 주소.
- 안에서는 백슬래시 이스케이프가 동작하지 않는다. 형식이 맞지 않으면 `<` 와 나머지는 글자 그대로다.

### 줄바꿈

- 문단·setext 제목 안의 줄바꿈: 바로 앞에 공백이 2칸 이상이면 강제 줄바꿈(그 공백은 모두 지운다), 바로 앞에 `\` 가 있으면 강제 줄바꿈(`\` 앞의 공백은 남는다), 그 밖에는 부드러운 줄바꿈(앞의 공백 1칸은 지운다). 다음 줄의 앞 공백은 지운다.
- 블록 내용 맨 끝의 공백과 `\` 는 줄바꿈이 아니다(공백은 지워지고 `\` 는 글자로 남는다).

### 링크 주소 인코딩 (`href`, `src`)

주소의 백슬래시 이스케이프를 푼 뒤 다음처럼 바꾸고, 그 결과를 HTML 이스케이프한다(`&` → `&amp;`).
- ASCII 영문자·숫자와 `` ;/?:@&=+$,-_.!~*'()# `` 는 그대로 둔다.
- `%` 뒤에 16진수 두 자리가 오면 그 세 글자를 그대로 둔다. 그 밖의 `%` 는 `%25` 로 바꾼다.
- 그 밖의 ASCII 문자(공백, `"`, `<`, `>`, `\`, `[`, `]`, `^`, `` ` ``, `{`, `|`, `}` 등)는 `%XX`(대문자 16진수)로, 비 ASCII 문자는 UTF-8 바이트마다 `%XX` 로 바꾼다. 예: `</ä b>` → `/%C3%A4%20b`.

제목(`title`)은 백슬래시 이스케이프를 푼 뒤 HTML 이스케이프만 한다. 자동 링크의 링크 텍스트와 이미지 `alt` 는 인코딩하지 않는다(HTML 이스케이프만).
