작업 폴더 최상위에 파이썬 패키지 `sheet`(표준 라이브러리만, Python 3.11 이상)를 만든다. 작은 스프레드시트 계산 엔진 라이브러리다. 패키지는 작업 폴더 바로 아래 `sheet/` 에 둔다(src 레이아웃 아님). 아래의 이름·시그니처·값의 타입은 그대로 지킨다. 다른 사람이 이 인터페이스로 테스트한다. 테스트도 함께 작성한다.

규칙이 많다. 엑셀과 비슷하지만 **이 문서가 기준**이다. 엑셀과 다른 곳이 있고, 엑셀의 의외의 동작을 따르는 곳은 "(엑셀과 같음)"이라고 적었다. 적힌 대로 정확히 구현한다.

## 1. 공개 API (`sheet` 에서 import)

- `Sheet()`: 빈 시트.
- `Error`: 오류 값 타입. `Error(code)` 로 만들고 속성 `code`(str)를 가진다. code 가 같으면 `==` 가 참이고 해시도 같다. `str(e) == e.code`. `str` 의 하위 클래스가 아니며 문자열과 같지 않다(`Error("#N/A") != "#N/A"`).
- `FormulaError`: 수식 문법 오류. `ValueError` 의 하위 클래스.

오류 code 는 다음 7가지다.

| code | 생기는 곳 |
|---|---|
| `#DIV/0!` | 0 으로 나눔, 0 의 음수 거듭제곱, 평균할 숫자가 없음 |
| `#VALUE!` | 숫자·논리값으로 바꿀 수 없는 값, 범위를 값으로 씀 |
| `#REF!` | 없어진 참조(복사·이동·행열 삭제 등) |
| `#NAME?` | 모르는 함수, 이름 |
| `#N/A` | 수식에 직접 쓴 `#N/A` |
| `#NUM!` | 결과가 유한한 수가 아님, `0^0`, 음수의 정수가 아닌 거듭제곱 |
| `#CYCLE!` | 순환 참조 (5.5) |

### 1.1 셀 주소와 시트 크기
- 열은 `A`…`Z`, `AA`…`AZ`, `BA`…`ZZ`, `AAA`…`XFD`(16384번째 열), 행은 1…1048576 이다. 이 밖의 셀은 없다.
- 셀 주소 인수(`ref`, `dst`)는 `열 글자 + 행 번호` 다. 대소문자 무시, `$` 없음, 행 번호는 0 으로 시작하지 않음, 시트 안이어야 한다. 아니면 `ValueError`(`"A0"`, `"A01"`, `"$A$1"`, `"XFE1"`, `"A1048577"`, `"A1:B2"`, `""` 모두 ValueError).
- 영역 인수(`src`)는 셀 주소 하나, 또는 `주소:주소`. 두 모서리는 어떤 순서여도 되고 그 두 셀을 모서리로 하는 직사각형이다(`"B3:A1"` = `"A1:B3"`). 아니면 ValueError.
- 열 인수(`col`)는 열 글자(`"C"`, `"aa"`, 대소문자 무시, 시트 안). 아니면 ValueError.

### 1.2 `Sheet` 메서드
- `set(ref, text: str) -> None`: 셀 내용을 정한다(2장). 수식 문법 오류면 `FormulaError` 를 내고 **셀은 원래대로 둔다**.
- `get(ref)`: 셀의 계산된 값. 빈 셀은 `None`, 그 밖에는 `int`, `float`, `str`, `bool`, `Error` 중 하나(3.1).
- `formula(ref) -> str`: 셀에 저장된 글자. 빈 셀은 `""`, 수식 셀은 정규화된 수식(4.3), 상수 셀은 `set` 에 준 글자 그대로.
- `copy(src, dst) -> None`, `move(src, dst) -> None`: 6장.
- `insert_rows(row: int, count: int = 1)`, `delete_rows(row: int, count: int = 1)`, `insert_cols(col: str, count: int = 1)`, `delete_cols(col: str, count: int = 1)`: 7장.
- 계산은 자동이다: 어떤 변경 뒤에도 `get` 은 늘 최신 값을 돌려준다.

## 2. 셀 입력 (`set` 의 text)

위에서부터 처음 맞는 규칙을 쓴다. 앞뒤 공백을 떼지 않는다.

1. `""`: 셀을 비운다(빈 셀이 된다).
2. `=` 로 시작: 수식. `=` 뒤가 수식 본문이다(4장).
3. `'` 로 시작: 글자. 값은 첫 `'` 를 뗀 나머지(`"'123"` → 글자 `"123"`, `"'"` → 빈 글자 `""`, `"''x"` → `"'x"`). 값이 빈 글자여도 **빈 셀이 아니다**.
4. 대소문자 무시로 정확히 `TRUE` 또는 `FALSE`: 논리값(`"true"` → True, `"TRUE "` 는 공백이 있어 6번).
5. 전체가 정규식 `[+-]?([0-9]+(\.[0-9]*)?|\.[0-9]+)([eE][+-]?[0-9]+)?` 에 맞음: 숫자(`"1.50"` → 1.5, `"5."` → 5, `"-.5"` → -0.5, `"+7"` → 7, `"1e3"` → 1000).
6. 그 밖: 그대로 글자(`" 42"`, `"1,000"`, `"1e"`, `"#DIV/0!"` 도 글자다).

## 3. 값

### 3.1 값의 종류
- **숫자**: 모든 계산은 float(IEEE 754 배정밀도)로 한다. `get` 은 정수값인 숫자(`x.is_integer()`)를 `int` 로, 아니면 `float` 로 돌려준다(`1.0` → `1`, `-0.0` → `0`, `10/4` → `2.5`, `1e3` → `1000`). 계산 결과(숫자 상수 포함)가 무한대·NaN 이면 `#NUM!`(예: `=1E308*10`, `=10^400`).
- **글자**(`str`), **논리값**(`bool`), **오류**(`Error`).
- **빈 칸**: 내용이 없는 셀. `get` 은 `None`. 계산 안에서는 아래 규칙대로 쓰인다.
- 수식의 결과가 빈 칸일 수는 없다(3.4).

### 3.2 바꾸기
- **숫자로**: 숫자는 그대로, 논리값은 TRUE → 1·FALSE → 0, 빈 칸은 0, 글자는 앞뒤 공백을 뗀 뒤(파이썬 `str.strip()`) 2장 5번 정규식에 전체가 맞으면 그 숫자, 아니면 `#VALUE!`(빈 글자 `""`, `"TRUE"`, `"50%"`, `"1,000"` 은 #VALUE!). 범위는 #VALUE!, 오류는 그 오류.
- **글자로**: 글자는 그대로, 논리값은 `"TRUE"`/`"FALSE"`, 빈 칸은 `""`, 숫자는 정수값이면 `str(int(x))`, 아니면 파이썬 `repr(x)` (예: `"1000"`, `"0.25"`, `"0.30000000000000004"`, `"1e-07"`, `1.5E20` → `"150000000000000000000"`). 범위는 #VALUE!, 오류는 그 오류.
- **논리값으로**(IF·NOT 의 조건): 논리값은 그대로, 숫자는 0 이 아니면 TRUE, 빈 칸은 FALSE, **글자는 무엇이든 `#VALUE!`**(`"TRUE"` 도), 범위는 #VALUE!, 오류는 그 오류.

### 3.3 비교 (`= <> < > <= >=`)
- 결과는 논리값이다. 피연산자를 **바꾸지 않고** 비교한다.
- 빈 칸은 상대가 숫자면 0, 글자면 `""`, 논리값이면 FALSE 로 보고 비교한다. 둘 다 빈 칸이면 같다.
- 종류가 다르면 **숫자 < 글자 < 논리값** 이다(엑셀과 같음): `=1<"a"` TRUE, `="z"<FALSE` TRUE, `=1="1"` FALSE(오류 아님), `=TRUE=1` FALSE, `=TRUE>100` TRUE.
- 숫자끼리는 float 값 그대로(`=0.1+0.2=0.3` 은 FALSE, 엑셀과 다름), 논리값끼리는 FALSE < TRUE, 글자끼리는 둘 다 `str.lower()` 한 뒤 파이썬 문자열 비교(`="abc"="ABC"` TRUE, `="_"<"a"` TRUE, `="10"<"9"` TRUE).

### 3.4 수식의 결과
수식의 최종 값이 범위면 `#VALUE!`, 빈 칸이면 `0` 이다(`=A1` 에서 A1 이 비었으면 0).

## 4. 수식 언어

### 4.1 토큰
공백(스페이스·탭·`\r`·`\n`)은 토큰 사이에서 무시된다(문자열 밖의 토큰 안에는 올 수 없다). 토큰의 첫 글자로 종류를 정한다.
- **숫자**: 숫자, 또는 `.` 바로 뒤에 숫자로 시작한다. 가장 긴 `([0-9]+(\.[0-9]*)?|\.[0-9]+)([eE][+-]?[0-9]+)?`. 부호는 숫자 토큰에 들지 않는다(단항 연산자다).
- **문자열**: `"` 로 시작해 `"` 로 끝난다. 안의 `""` 는 `"` 하나. 닫히지 않으면 문법 오류.
- **오류 값**: `#DIV/0!`, `#VALUE!`, `#REF!`, `#NAME?`, `#N/A`, `#NUM!` (대소문자 무시). `#` 로 시작했는데 이 중 어느 것도 아니면 문법 오류(`#CYCLE!` 은 수식에 쓸 수 없다).
- **낱말**: 영문자·`_`·`$` 로 시작해 영문자·숫자·`_`·`$` 가 이어지는 가장 긴 글자열. 아래 순서로 정한다.
  1. 바로 뒤(공백 없이) 글자가 `(` 이면 함수 이름. 낱말에 `$` 가 있으면 문법 오류.
  2. `$?[A-Za-z]{1,3}$?[1-9][0-9]*` 꼴이고 시트 안이면 셀 참조(`$` 가 붙은 열·행은 절대 좌표).
  3. 대소문자 무시로 `TRUE`/`FALSE` 면 논리값.
  4. `$` 가 없으면 **이름**이다(예: `foo`, `A0`, `XFE1`, `AAAA1`, `A1B`, `_x1`). 이름의 값은 `#NAME?` 이다(문법 오류 아님).
  5. 그 밖(`$` 가 섞인 셀 참조가 아닌 낱말, 예 `A$0`, `$A`)은 문법 오류.
- **연산자**: `<=` `>=` `<>`(두 글자를 먼저 본다), `+ - * / ^ & = < > %`, 그리고 `( ) , :`.
- 그 밖의 글자(예 `@`)는 문법 오류.

### 4.2 문법과 우선순위
우선순위가 낮은 것부터. 이항 연산자는 모두 **왼쪽 결합**이다.

1. 비교 `= <> < > <= >=` — `=1<2<3` 은 `(1<2)<3` = `TRUE<3` = FALSE
2. 이어붙이기 `&`
3. 덧셈·뺄셈 `+ -`
4. 곱셈·나눗셈 `* /`
5. 거듭제곱 `^` — **왼쪽 결합**(엑셀과 같음): `=2^3^2` = 64
6. 백분율 `%` (피연산자 뒤에 붙고 여러 번 올 수 있다): `=10%%` = 0.001
7. 단항 `-` `+` (앞에 붙고 여러 번 올 수 있다) — **`%` 와 `^` 보다 먼저 묶인다**(엑셀과 같음): `=-2^2` = 4, `=-2%` 는 `(-2)%`, `=2^-1` = 0.5
8. 기본 식: 숫자, 문자열, 논리값, 오류 값, 이름, 셀 참조, 범위 `셀참조:셀참조`, 함수 호출 `함수이름(인수, ...)`, 괄호 `( 식 )`

- 범위는 셀 참조 두 개를 `:` 로 이은 것뿐이다. 그 밖의 `:` 는 문법 오류(`=A1:1`, `=A1:B2:C3`). 범위는 단항 연산자보다 먼저 묶인다(`=-A1:A2` 는 범위에 `-` 를 붙인 것).
- 함수 인수는 쉼표로 나눈 식이다. 빈 인수(`SUM(1,,2)`, `SUM(1,)`)는 문법 오류. 인수 없는 호출 `F()` 는 문법상 허용된다.
- 5.3 의 함수는 인수 개수가 맞지 않으면 문법 오류(`SUM()`, `IF(1)`, `ROUND(1)`, `NOT(1,2)`). 모르는 함수는 인수 개수와 상관없이 문법 오류가 아니고 값이 `#NAME?` 이다.
- 식이 비었거나(`=` 만), 토큰이 남거나(`=1 2`), 괄호가 맞지 않거나, 피연산자가 빠지면(`=1+`, `=1+*2`) 문법 오류. `=SUM (1)` 도 문법 오류다(공백 때문에 `SUM` 은 이름이고, 그 뒤에 괄호식이 붙은 꼴).

### 4.3 정규화 (`formula()` 가 돌려주는 수식 글자)
- `=` 뒤에 토큰을 **공백 없이** 이어 쓴다. 괄호는 쓴 그대로 남는다(`=((1))`).
- 함수 이름·이름·셀 참조·논리값·오류 값은 대문자로. 숫자는 쓴 그대로이되 지수의 `e` 는 `E` 로(`1.50e2` → `1.50E2`, `.5` → `.5`). 문자열은 쓴 그대로(안의 대소문자·공백·`""` 그대로).
- **범위 모서리 정규화**: 열과 행을 따로, 작은 쪽을 앞(왼쪽 위)에 둔다. `$` 표시는 그 좌표를 따라간다. 같으면 쓴 순서 그대로. 예: `B3:A1` → `A1:B3`, `$B$3:A1` → `A1:$B$3`, `B$1:$A3` → `$A$1:B3`, `A2:$A1` → `A1:$A2`.
- 예: `= sum( a1 , b2:a1 )*2` → `=SUM(A1,A1:B2)*2`, `=if(true,#n/a,foo)` → `=IF(TRUE,#N/A,FOO)`.
- 복사·이동·행열 삽입/삭제로 참조가 바뀌면 같은 규칙으로 다시 쓴다. `#REF!` 가 된 참조는 오류 값 토큰 `#REF!` 로 쓴다.

## 5. 계산

### 5.1 참조
- 셀 참조의 값은 그 셀의 값이다(빈 셀이면 빈 칸). 괄호는 값을 바꾸지 않는다(`=(A1)` 도 A1 의 값, 빈 칸이면 빈 칸).
- 범위는 그 자체로는 값이 아니다. 아래 함수의 **참조 인수**로만 쓸 수 있다. 그 밖의 자리(연산자의 피연산자, 수식의 최종 값, 참조 인수를 받지 않는 함수의 인수 등)에서 범위의 값은 `#VALUE!` 다.
- 참조 인수를 따로 다루는 함수는 SUM·AVERAGE·MIN·MAX·COUNT·COUNTA·AND·OR·CONCAT·COUNTIF·SUMIF 뿐이다. 이 함수들에서 인수가 셀 참조나 범위 **그 자체**(괄호로 감싼 것 포함, 예 `(A1:B2)`)이면 참조 인수, 그 밖(`A1+0`, `-A1`, `IF(...)` 등)은 **값 인수**다. 그 밖의 함수(IF·IFERROR·NOT·ROUND·ABS·LEN·UPPER)는 모든 인수를 값으로 계산한다(셀 참조는 그 셀의 값, 범위는 #VALUE!).
- 참조 인수의 셀은 **행 우선** 순서로 본다(위 행부터, 한 행 안에서는 왼쪽부터). "처음 만난 오류"를 고를 때 이 순서를 쓴다.

### 5.2 연산자
- 산술 `+ - * / ^`: 왼쪽 피연산자를 계산해 숫자로 바꾸고(오류면 그 오류가 결과), **그다음** 오른쪽을 계산해 숫자로 바꾼다(오류면 그 오류가 결과). 둘 다 숫자일 때 연산한다. 그래서 `="a"+1/0` 은 `#VALUE!`, `=1/0+"a"` 는 `#DIV/0!`, `="a"/0` 은 #VALUE!.
  - `/`: 오른쪽이 0 이면 `#DIV/0!`(`=1/A1` 에서 A1 이 빈 칸이어도 #DIV/0!).
  - `^`: `0^0` 은 `#NUM!`, 0 의 음수 거듭제곱(`0^-1`)은 `#DIV/0!`, 음수의 정수가 아닌 거듭제곱은 `#NUM!`(`=(-8)^(1/3)`, 그리고 단항 `-` 가 먼저 묶이므로 `=-8^(1/3)` 도 #NUM!), 결과가 넘치면 `#NUM!`.
- 단항 `-`: 숫자로 바꿔 부호를 바꾼다(`=-"3"` → -3, `=-"a"` → #VALUE!, `=-TRUE` → -1).
- **단항 `+` 는 값을 바꾸지 않는다**(엑셀과 같음): `=+"a"` → `"a"`, `=+TRUE` → TRUE. 다만 빈 칸은 0, 범위는 #VALUE!, 오류는 그 오류.
- `%`: 숫자로 바꿔 100 으로 나눈다(`="50"%` → 0.5).
- `&`: 왼쪽을 글자로 바꾸고(오류면 그 오류) 그다음 오른쪽을 글자로 바꿔(오류면 그 오류) 잇는다. `=1+2&3` → `"33"`, `=A1&"x"`(A1 빈 칸) → `"x"`, `=TRUE&1` → `"TRUE1"`.
- 비교: 왼쪽 값이 오류면 그 오류, 아니면 오른쪽 값이 오류면 그 오류, 아니면 3.3 (범위는 #VALUE!).
- 오류 값 상수(`=#N/A`)의 값은 그 오류, 이름의 값은 `#NAME?`.

### 5.3 함수
함수 이름은 대소문자를 무시한다. 아래 18개 밖의 함수는 값이 `#NAME?` 이고 **인수를 계산하지 않는다**. "숫자로·글자로·논리값으로"는 3.2 의 바꾸기다. 별말이 없으면 인수를 왼쪽부터 처리하고 처음 만난 오류가 결과다.

**숫자 모으기** (SUM·AVERAGE·MIN·MAX 공통):
- 참조 인수: 그 셀들 중 **숫자인 셀만** 모은다. 글자(숫자처럼 보여도)·논리값·빈 칸은 건너뛴다. 오류인 셀이 있으면 그 오류(행 우선으로 처음 것).
- 값 인수: 숫자로 바꿔서 모은다(`TRUE` → 1, `"2"` → 2, `"x"` → #VALUE!, 오류는 그 오류).
- 예(엑셀과 같음): `SUM(TRUE,"2")` = 3. A1 이 TRUE 면 `SUM(A1)` = 0. A1 이 글자 `"5"` 면 `SUM(A1)` = 0 이지만 `SUM(A1+0)` = 5.

| 함수 | 동작 |
|---|---|
| `SUM(x, ...)` | 모은 숫자를 **모은 순서대로 왼쪽부터 하나씩** float 로 더한다(`SUM(0.1,0.2,0.3)` = 0.6000000000000001). 모은 것이 없으면 0 |
| `AVERAGE(x, ...)` | SUM 과 같은 방식으로 더한 합 ÷ 개수. 모은 숫자가 없으면 `#DIV/0!` |
| `MIN(x, ...)`, `MAX(x, ...)` | 가장 작은/큰 값. 모은 숫자가 없으면 0 |
| `COUNT(x, ...)` | 오류를 내지 않는다. 참조 인수: 숫자인 셀의 수(오류 셀도 세지 않는다). 값 인수: 계산한 값이 숫자·논리값이거나 숫자로 바꿀 수 있는 글자면 1, 아니면(오류 포함) 0 |
| `COUNTA(x, ...)` | 오류를 내지 않는다. 참조 인수: 빈 칸이 아닌 셀의 수(오류 셀, 빈 글자 셀, `""` 를 돌려주는 수식 셀 포함). 값 인수: 무엇이든(오류여도) 1 |
| `AND(x, ...)`, `OR(x, ...)` | 논리값을 모은다. 참조 인수: 논리값과 숫자(0 이 아니면 TRUE)인 셀만, 글자·빈 칸은 건너뛰고 오류 셀이면 그 오류. 값 인수: 논리값·숫자는 위와 같고 글자는 `#VALUE!`, 오류는 그 오류. **모든 인수를 처리한다**(결과가 이미 정해져도 뒤의 오류가 결과다: `AND(FALSE,1/0)` → #DIV/0!). 모은 것이 하나도 없으면 `#VALUE!`. AND 는 모두 TRUE 인지, OR 는 하나라도 TRUE 인지 |
| `IF(cond, then[, else])` | cond 를 논리값으로(오류면 그 오류). 참이면 then **만**, 거짓이면 else **만** 계산한다(고르지 않은 쪽의 오류는 결과에 영향이 없다). else 가 없고 거짓이면 FALSE. 고른 쪽의 값이 빈 칸이면 0, 범위면 #VALUE! (그래서 `=IF(TRUE,A1)&"x"` 는 A1 이 빈 칸이면 `"0x"`) |
| `IFERROR(x, alt)` | x 를 계산한다(빈 칸이면 0, 범위면 #VALUE!). 오류가 아니면 그 값, 오류면 그때만 alt 를 계산한 값(빈 칸이면 0, 범위면 #VALUE!) |
| `NOT(x)` | 논리값으로 바꿔 뒤집는다 |
| `ROUND(x, d)` | x 를 숫자로, 그다음 d 를 숫자로 바꾼다. d 는 0 쪽으로 잘라 정수로 만든다(2.9 → 2, -0.9 → 0, -1.5 → -1). x 의 십진 표기 `repr(x)` 를 기준으로 소수점 아래 d 자리까지(d 가 음수면 10^(-d) 단위로) **0 에서 먼 쪽으로 반올림**한 정확한 십진 값을 float 로 바꾼 것이 결과다. `ROUND(2.5,0)` = 3, `ROUND(-2.5,0)` = -3, `ROUND(0.125,2)` = 0.13, `ROUND(2.675,2)` = 2.68, `ROUND(1.005,2)` = 1.01, `ROUND(1250,-2)` = 1300, `ROUND(1234.567,-2)` = 1200 |
| `ABS(x)` | 숫자로 바꿔 절댓값 |
| `CONCAT(x, ...)` | 참조 인수는 셀마다(행 우선, 빈 칸은 `""`), 값 인수는 그 값을 글자로 바꿔 모두 잇는다. 오류는 그 오류 |
| `LEN(x)` | 글자로 바꾼 것의 길이(파이썬 `len`): `LEN(0.5)` = 3, `LEN(TRUE)` = 4, `LEN(1E3)` = 4, 빈 칸은 0 |
| `UPPER(x)` | 글자로 바꿔 `str.upper()` |
| `COUNTIF(range, crit)` | 5.4 |
| `SUMIF(range, crit[, sum_range])` | 5.4 |

인수 개수: SUM·AVERAGE·MIN·MAX·COUNT·COUNTA·AND·OR·CONCAT 은 1개 이상, IF 는 2~3개, IFERROR·ROUND·COUNTIF 는 2개, SUMIF 는 2~3개, NOT·ABS·LEN·UPPER 는 1개.

### 5.4 COUNTIF·SUMIF
- 처리 순서: `range` → `crit` → (SUMIF) `sum_range`. `range` 와 `sum_range` 는 참조 인수여야 한다. 아니면 그 인수를 계산해서 오류면 그 오류, 아니면 `#VALUE!` 가 결과다(`COUNTIF(1,">0")` → #VALUE!, `COUNTIF(#REF!,1)` → #REF!). `crit` 은 계산해서 오류면 그 오류, 범위면 #VALUE!.
- **조건 만들기** → (연산자, 피연산자):
  - crit 이 숫자나 논리값이면 (`=`, 그 값).
  - crit 이 빈 칸(빈 셀을 참조)이면 (`=`, 빈 글자 `""`).
  - crit 이 글자면: 맨 앞에 `<=`, `>=`, `<>`, `<`, `>`, `=` 중 하나가 있으면(이 순서로 확인) 그것이 연산자이고, 없으면 연산자는 `=` 다. 연산자를 뗀 나머지 글자가 2장 5번 정규식에 전체가 맞으면 피연산자는 그 숫자, 대소문자 무시로 `TRUE`/`FALSE` 면 그 논리값, 아니면 그 글자다(`"5"`, `"=5"` → 숫자 5, `"true"` → TRUE, `"<b"` → 글자 `"b"`, `"<>"` → (`<>`, `""`)).
- **셀 값 v 가 조건에 맞는지** — 오류인 셀은 **어떤 조건에도 맞지 않는다**(`<>` 도). 빈 셀은 빈 칸으로 본다.
  - `=`: 피연산자가 숫자면 v 가 같은 숫자일 때(숫자처럼 보이는 글자 셀은 맞지 않는다). 논리값이면 v 가 같은 논리값일 때. 빈 글자면 v 가 빈 칸이거나 빈 글자일 때. 그 밖의 글자면 v 가 글자이고 와일드카드 패턴에 맞을 때: 대소문자 무시, 전체가 맞아야 함, `*` 는 아무 글자열(빈 것 포함), `?` 는 아무 글자 하나, `~*` `~?` `~~` 는 글자 그대로의 `*` `?` `~`(그 밖의 `~` 는 그냥 `~` 글자). 그래서 `"*"` 는 글자 셀에만 맞고 빈 칸에는 맞지 않는다.
  - `<>`: `=` 에 맞지 않는 모든 값(빈 칸 포함, 오류 제외). 예: 범위 안의 빈 셀도 `"<>apple"` 에 맞는다.
  - `<` `>` `<=` `>=`: 피연산자와 **같은 종류의 값만** 비교한다. 숫자는 숫자 셀과, 논리값은 논리값 셀과, 글자는 글자 셀과(둘 다 `str.lower()` 해서 비교, 와일드카드 없음). 빈 칸은 맞지 않는다.
- `COUNTIF`: range 의 모든 칸(빈 칸 포함) 가운데 조건에 맞는 칸의 수.
- `SUMIF`: range 의 칸 중 조건에 맞는 칸마다 "더할 칸"을 정하고, 그 값이 숫자면 range 의 행 우선 순서로 하나씩 더한다(글자·논리값·빈 칸은 건너뜀, 더할 칸이 오류면 그 오류가 결과). 더할 칸은 sum_range 가 없으면 그 칸 자신, 있으면 **sum_range 의 왼쪽 위 셀에서 같은 위치만큼 떨어진 칸**이다. 즉 sum_range 는 크기와 상관없이 왼쪽 위 셀만 쓰고 range 와 같은 크기로 본다(엑셀과 같음: `SUMIF(A1:A3,">0",B1)` 과 `SUMIF(A1:A3,">0",B1:B2)` 는 B1:B3 에서 더한다). 시트 밖의 칸은 빈 칸이다. range 안의 오류 셀은 조건에 맞지 않을 뿐 오류를 내지 않는다.

### 5.5 재계산과 순환 참조
- 수식의 **의존 셀** = 수식에 적힌 모든 셀 참조와 모든 범위 안의 셀(IF 의 고르지 않은 쪽, 모르는 함수의 인수 안에 있어도 포함) + SUMIF 의 sum_range 를 range 크기로 맞춘 영역.
- 의존 관계를 따라가면 자기 자신으로 돌아오는 수식 셀(자기 참조, 자기를 포함한 범위 포함)은 모두 값이 `#CYCLE!` 이다. 실제 계산에서 그 참조를 쓰는지와 상관없다: A1 이 `=IF(TRUE,1,B1)`, B1 이 `=A1` 이면 둘 다 #CYCLE!, A5 가 `=SUM(A1:A10)` 이면 #CYCLE!.
- 순환에 들지 않은 셀이 순환 셀을 참조하면, `#CYCLE!` 은 보통 오류 값처럼 전파된다(`=A1+1` → #CYCLE!, `=IFERROR(A1,0)` → 0, `COUNT` 는 세지 않고 `COUNTA` 는 센다).
- 순환을 끊으면(셀을 바꾸거나 지우거나 행을 지우면) 다시 정상 값이 된다.
- 성능:
  - A1 에 숫자, A2 에 `=A1+1`, …, A10000 에 `=A9999+1` 을 차례로 넣고 A10000 을 읽고, A1 을 바꿔 다시 읽고, A1 을 `=A10000` 으로 바꿔 1만 칸짜리 순환을 만들고 읽는 것이 모두 합쳐 **10초 안에, 재귀 한도 오류 없이** 끝나야 한다.
  - 범위 계산·의존 관계·순환 판정이 **범위의 넓이에 비례하면 안 된다**(비어 있지 않은 셀의 수에 비례하면 된다). `SUM(A1:J100000)`, `COUNTIF(A1:J100000,"")`, `MAX(A1:XFD1048576)` 같은 범위가 있어도 비어 있지 않은 셀이 몇 개뿐이면 1초 안에 계산해야 한다.

## 6. 복사와 이동

### 6.1 `copy(src, dst)`
- src 영역을 왼쪽 위가 dst 인 같은 크기의 영역으로 복사한다. 붙일 영역이 시트를 벗어나면 ValueError 이고 아무것도 바뀌지 않는다.
- **원본 영역 전체를 먼저 떠 놓고** 붙인다. 원본과 붙일 곳이 겹쳐도 원본의 원래 내용이 복사된다. 원본의 빈 셀은 붙일 곳의 셀을 비운다.
- 상수 셀은 `set` 에 준 글자 그대로 복사된다(`formula()` 도 같다).
- 수식 셀은 참조를 옮긴다. 이동 거리 = (dst 의 열·행) − (src 왼쪽 위의 열·행). `$` 가 없는 좌표에만 이동 거리를 더하고 `$` 가 붙은 좌표는 그대로 둔다(`$A1` 은 행만, `A$1` 은 열만 옮겨진다).
  - 옮긴 셀 참조가 시트 밖(열 < A 또는 > XFD, 행 < 1 또는 > 1048576)이면 그 참조는 `#REF!` 가 된다: `C1` 의 `=A1+B1` 을 B1 로 복사 → `=#REF!+A1`.
  - 범위는 두 모서리를 각각 옮긴다. 하나라도 시트 밖이면 범위 전체가 `#REF!` 하나가 된다(`=SUM(#REF!)`). 아니면 모서리를 다시 정규화한다(4.3): `B1:$C1` 을 오른쪽으로 두 칸 → `$C1:D1`.
  - 문자열 안의 글자, 함수 이름, 이미 있는 `#REF!` 는 참조가 아니므로 바뀌지 않는다.

### 6.2 `move(src, dst)`
잘라 붙이기다. 붙일 영역이 시트를 벗어나면 ValueError 이고 아무것도 바뀌지 않는다. 원본 영역을 S, 붙일 영역을 D 라 한다.
1. 먼저 **시트의 모든 수식**(S 안의 수식 포함)의 참조를 바꾼다.
   - S 안의 셀을 가리키는 셀 참조는 이동 거리만큼 옮긴다(`$` 와 상관없이, `$` 표시는 그대로).
   - S 밖이면서 D 안인 셀(덮어써질 셀)을 가리키는 셀 참조는 `#REF!` 가 된다.
   - 범위는 **두 모서리가 모두 S 안**이면(범위 전체가 S 안이면) 두 모서리를 옮긴다. 아니면 그대로 둔다(D 와 겹쳐도 그대로).
   - 그 밖의 참조는 그대로다. 복사와 달리, 옮겨지는 수식 자신이 S 밖을 가리키는 참조는 바뀌지 않는다.
2. S 의 셀들을 떠 놓고, S 와 D 를 비운 뒤, 떠 놓은 셀을 D 의 같은 위치에 놓는다(원본의 빈 셀 자리는 비어 있게 된다).

## 7. 행·열 삽입과 삭제
행으로만 적는다. 열(`insert_cols`, `delete_cols`)도 열 좌표에 똑같이 적용한다(마지막 열은 XFD = 16384).

- 인수: `row` 는 1~1048576 정수, `count` 는 1 이상 정수, `col` 은 열 글자. 아니면 ValueError. `delete_rows` 는 `row + count - 1` 이 1048576 이하, `delete_cols` 는 (열 번호 + count − 1) 이 16384 이하여야 한다(아니면 ValueError). ValueError 일 때는 아무것도 바뀌지 않는다.
- 참조 바꾸기는 **시트의 모든 수식**에 적용한다. 참조가 가리키는 좌표로만 정하며 `$` 와 상관없다(절대 참조도 옮겨진다. `$` 표시는 그대로). 그 수식 셀 자신이 옮겨지는지와도 상관없다.

### 7.1 `insert_rows(row, count)`
- `row` 행 앞에 빈 행 count 개를 넣는다. 행 번호가 `row` 이상인 셀은 count 만큼 아래로 간다. 비어 있지 않은 셀이 1048576 행을 넘어가게 되면 ValueError 이고 아무것도 바뀌지 않는다.
- 셀 참조: 행이 `row` 이상이면 +count. 그 결과가 1048576 을 넘으면 `#REF!`.
- 범위(행 a..b): `row ≤ a` 면 a, b 둘 다 +count(범위의 첫 행에 넣으면 범위가 통째로 옮겨진다), `a < row ≤ b` 면 b 만 +count(범위가 늘어난다), `row > b` 면 그대로(마지막 행 바로 다음에 넣어도 늘어나지 않는다). 그 뒤 a 가 1048576 을 넘으면 범위 전체가 `#REF!`, b 만 넘으면 b = 1048576.

### 7.2 `delete_rows(row, count)`
- `row` … `row+count-1` 행을 지운다(그 안의 셀은 사라진다). 그 아래 셀은 count 만큼 위로 간다.
- 셀 참조: 지운 행을 가리키면 `#REF!`, 그 아래를 가리키면 −count.
- 범위(행 a..b): 지우고 **남은 행들**의 새 위치를 덮는 범위가 된다(줄어든다). 남은 행이 없으면 범위 전체가 `#REF!` 하나가 된다. 예: `A2:A6` 에서 3행 삭제 → `A2:A5`, 1~2행 삭제 → `A1:A4`, 5~7행 삭제 → `A2:A4`, 2~6행 삭제 → `#REF!`.
- 수식 글자도 그렇게 바뀐다: `=A5+A6` 에서 5행 삭제 → `=#REF!+A5`, `=SUM(A2:A3)` 에서 2~3행 삭제 → `=SUM(#REF!)`.
