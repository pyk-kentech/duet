간단한 INI 파서 Python 패키지 `inimini` 를 만든다.

- 패키지는 작업 폴더 최상위의 `inimini/` 에 둔다 (src 레이아웃을 쓰지 말 것). 표준 라이브러리만 쓰고 `configparser` 는 쓰지 않는다.
- 아래 이름과 동작을 정확히 지킨다. 다른 사람이 이 인터페이스로 테스트한다.

## `inimini.parse(text: str) -> dict[str, dict[str, str]]`

- 줄 끝은 `\n` 또는 `\r\n`.
- `[이름]` 줄이 섹션을 시작한다. 이름은 대괄호 안을 앞뒤 공백 제거한 것. 같은 섹션이 다시 나오면 앞의 내용에 이어서 합친다. 키가 없는 섹션도 결과에 빈 dict 로 들어간다.
- `키 = 값` 줄: **첫 번째** `=` 를 기준으로 나누고 키와 값의 앞뒤 공백을 제거한다. 키는 대소문자를 구분한다. 값은 비어도 된다.
- 첫 섹션보다 앞에 있는 키는 섹션 `""`(빈 문자열)에 들어간다. 그런 키가 없으면 결과에 `""` 섹션을 넣지 않는다.
- 같은 섹션에서 같은 키가 다시 나오면 나중 값이 이긴다.
- 빈 줄(공백만 있는 줄 포함)과, 앞의 공백을 뺀 첫 글자가 `;` 또는 `#` 인 줄은 무시한다. 값 중간의 `;`, `#` 은 값의 일부다.
- 값이 큰따옴표로 시작하고 끝나면(길이 2 이상) 바깥 따옴표 한 쌍을 벗기고 안의 내용(공백 포함)을 그대로 쓴다.
- 잘못된 줄이면 `inimini.ParseError` 를 낸다. `ParseError` 는 `ValueError` 의 하위 클래스이고, `lineno` 속성에 1부터 센 줄 번호가 있다. 잘못된 줄: `=` 가 없는 줄, `]` 로 끝나지 않는 `[` 줄, 이름이 빈 섹션(`[]`, `[  ]`), 키가 빈 줄(`= 값`).

## `inimini.dumps(data: dict[str, dict[str, str]]) -> str`

- `parse` 의 반대. 섹션 `""` 의 키를 맨 앞에 섹션 헤더 없이 쓰고, 나머지 섹션은 dict 순서대로 쓴다.
- 값에 앞뒤 공백이 있거나 값이 큰따옴표로 시작하고 끝나면 큰따옴표로 감싼다.
- `parse(dumps(d)) == d` 가 되어야 한다 (키와 섹션 이름은 앞뒤 공백·`=`·줄바꿈이 없고, `;`·`#`·`[` 로 시작하지 않으며, 값에는 줄바꿈이 없다고 가정한다).
