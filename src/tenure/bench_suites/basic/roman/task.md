로마 숫자를 변환하는 Python 패키지 `roman` 을 만든다.

- 패키지는 작업 폴더 최상위의 `roman/` 에 둔다 (src 레이아웃을 쓰지 말 것). 표준 라이브러리만 쓴다.
- 아래 이름과 동작을 정확히 지킨다. 다른 사람이 이 인터페이스로 테스트한다.

## 인터페이스

`roman.to_roman(n) -> str`
- 1 이상 3999 이하의 정수를 표준 로마 숫자로 바꾼다. 대문자, 뺄셈 표기(IV, IX, XL, XC, CD, CM)를 쓴다.
- 범위를 벗어나거나 `int` 가 아니면 `ValueError`. `bool`(True/False)도 정수로 받지 않는다.

`roman.from_roman(s) -> int`
- 표준 형식의 로마 숫자만 받아 정수로 바꾼다.
- 다음은 모두 `ValueError`: 문자열이 아닌 값, 빈 문자열, 소문자, 앞뒤 공백, 로마 숫자가 아닌 글자, 비표준 형식(예: `IIII`, `VV`, `IC`, `IIV`, `MMMM`).
- 즉 `from_roman(s)` 가 성공하면 항상 `to_roman(from_roman(s)) == s` 이다.

CLI: `python -m roman <값>`
- 값이 숫자면 로마 숫자로, 로마 숫자면 정수로 바꿔 한 줄로 출력하고 종료 코드 0.
- 잘못된 값이면 표준 출력에는 아무것도 쓰지 않고, 표준 오류에 오류 메시지를 쓰고 종료 코드 1.
