작업 폴더 최상위에 파이썬 패키지 `minire`(표준 라이브러리만, Python 3.11 이상)를 만든다. 파이썬 `re` 모듈의 **부분집합**을 처음부터 직접 구현한 정규식 엔진이다(역추적 방식이면 충분하다). 패키지는 작업 폴더 바로 아래 `minire/` 에 둔다(src 레이아웃 아님). 아래의 이름·시그니처는 그대로 지킨다. 다른 사람이 이 인터페이스로 테스트한다. 테스트도 함께 작성한다.

- **패키지 코드는 `re`, `sre_compile`, `sre_parse`, `sre_constants`, `_sre`, `regex`, `fnmatch` 를 import 하거나 쓰면 안 된다**(정규식을 내부에서 쓰는 다른 모듈로 매칭을 대신하는 것도 금지). 채점이 `minire/` 폴더 안의 모든 `.py` 파일을 검사하므로, `re` 를 쓰는 테스트는 패키지 밖(예: 작업 폴더의 `tests/`)에 둔다. 테스트에서 `re` 를 비교 대상으로 쓰는 것은 괜찮다.
- 패턴과 대상은 `str` 만 다룬다(bytes 없음).

## 기준

**아래 부분집합 안에서, 같은 입력(패턴, 플래그, 대상 문자열, 연산과 인자)에 대한 결과는 파이썬 3.11+ `re` 의 결과와 같아야 한다**: 매치 여부와 위치, 각 그룹의 값과 위치, `lastindex`·`lastgroup`, findall·split·sub 의 결과, 예외의 종류. 채점은 같은 입력을 `re` 와 `minire` 에 넣어 비교한다. 아래의 "규칙"들은 re 의 동작 중 틀리기 쉬운 것을 풀어 적은 것이다.

## 지원하는 문법 (이것만 시험한다)

- 보통 문자: 메타문자 `. ^ $ * + ? { [ \ | ( )` 가 아닌 문자는 그 문자와 맞는다. `]` 와 `}` 는 보통 문자다.
- `\` + ASCII 영문자·숫자가 아닌 문자: 그 문자 자체(`\.` `\\` `\(` `\-` `\ ` `\#` 등, 비 ASCII 문자도 같다).
- `\n` `\t` `\r` `\f` `\v`: 줄바꿈·탭·CR·FF·VT 문자.
- `.`: `\n` 을 뺀 모든 문자(`DOTALL` 이면 `\n` 도).
- `\d` `\D` `\w` `\W` `\s` `\S`: 아래 유니코드 정의.
- 문자 클래스 `[...]`, 부정 클래스 `[^...]`.
- 앵커 `^` `$` `\A` `\Z` `\b` `\B`.
- 캡처 그룹 `(...)`, 비캡처 그룹 `(?:...)`, 이름 그룹 `(?P<name>...)`.
- 역참조 `\1` … `\99`, `(?P=name)`.
- 대안 `A|B`(빈 대안도 된다: `a|`, `|a`, `()|`).
- 수량자 `*` `+` `?` `{m}` `{m,}` `{,n}` `{m,n}` `{,}`, 그리고 각각 뒤에 `?` 를 붙인 게으른 형태(`*?` `+?` `??` `{m,n}?` …).
- 전방 탐색 `(?=...)` `(?!...)`, 고정 너비 후방 탐색 `(?<=...)` `(?<!...)`. 탐색 안에도 위 문법을 모두 쓸 수 있다(후방 탐색 안의 역참조는 빼고).
- 플래그 `IGNORECASE`(`I`), `MULTILINE`(`M`), `DOTALL`(`S`)와 그 조합(`|`).

다루지 않는 것(시험하지 않는다): 인라인 플래그 `(?i)`·`(?#...)`·조건 `(?(1)...)`·원자 그룹 `(?>...)`·소유 수량자(`*+` `++` `?+` `{m,n}+`), `\a` `\x` `\u` `\U` `\N{...}` `\z` `\0`·8진수 escape(`\` 뒤 숫자 세 자리), 클래스 안의 숫자 escape, 클래스 안의 `[` `&&` `--` `||` `~~`, VERBOSE·ASCII·LOCALE 플래그, 후방 탐색 안의 역참조, 수량자를 붙인 전방·후방 탐색, 아주 큰 반복 횟수, 빈 대상(또는 endpos 가 0)에서의 `\B`, pos > endpos 인 `match`·`fullmatch`.

## 규칙: escape 와 중괄호

- 위 목록에 없는 `\` + ASCII 영문자(예 `\q`, `\j`, `\y`)는 `error`(단 '다루지 않는 것'의 `\a \x \u \U \N \z` 는 시험하지 않는다). 패턴이 `\` 하나로 끝나면 `error`.
- `\` + 숫자는 역참조다(아래).
- `{` 는 올바른 수량자 모양 — `{`, ASCII 숫자 0개 이상, (`,`, 숫자 0개 이상), `}` — 일 때만 수량자이고, 아니면 보통 문자다: `a{}`, `a{x}`, `a{1,b}`, `a{1`, `a{ 1}`, `{` 는 모두 글자 그대로. 수량자에서 m 이 비면 0, n 이 비면 무한이다: `{,n}` 은 0~n 회, `{m,}` 은 m 회 이상, `{,}` 는 `*` 와 같다. m > n 이면 `error`.
- 반복할 것이 없으면 `error`("nothing to repeat"): 패턴·그룹·대안의 맨 앞에 수량자가 오거나(`*a`, `(+a)`, `a|*b`, `{2}`), 수량자 앞이 앵커(`^` `$` `\A` `\Z` `\b` `\B`)일 때. 수량자 바로 뒤에 또 수량자가 오면 `error`("multiple repeat": `a**`, `a{2}*`, `a*??` — 게으름 표시 `?` 는 한 번만 붙는다). 그룹으로 감싸면 된다(`(?:a*)*`).

## 규칙: 문자 클래스

- `[` 바로 뒤(부정 `^` 가 있으면 그 뒤)의 `]` 는 보통 문자다: `[]a]` 는 `]` 또는 `a`, `[^]a]` 는 그 둘이 아닌 문자. 그래서 `[]` 와 `[^]` 는 닫히지 않은 클래스라 `error`. 닫는 `]` 가 없어도 `error`.
- `-` 는 맨 앞, 맨 뒤, 범위 바로 뒤에서는 보통 문자다: `[-a]`, `[a-]`, `[a-c-e]`(a, b, c, `-`, e). 범위의 양 끝은 한 글자(보통 문자 또는 한 글자를 뜻하는 escape, 예 `[\n-\r]`)여야 한다: `[\d-z]` 는 `error`, `[\d-]` 는 숫자 또는 `-`. 끝이 시작보다 작으면(`[z-a]`) `error`.
- `^` 는 맨 앞에서만 부정이고, 다른 자리에서는 보통 문자다.
- 클래스 안의 escape: `\d \D \w \W \s \S`, `\n \t \r \f \v`, **`\b` 는 백스페이스(`\x08`)** (클래스 밖의 `\b` 는 단어 경계), `\` + ASCII 영숫자가 아닌 문자(`\]` `\\` `\-` `\^` 등). 그 밖의 `\` + ASCII 영문자(`\A` `\Z` `\B` `\q` …)는 `error`.
- 클래스 안의 다른 메타문자(`. * + ? ( ) { } | $`)는 보통 문자다.
- 부정 클래스 `[^...]` 는 `\n` 과도 맞는다(`.` 과 다르다).

## 규칙: 유니코드 정의 (한 문자 c 에 대해)

- `\d`: `c.isdecimal()`. `\w`: `c.isalnum() or c == "_"`. `\s`: `c.isspace()`. `\D` `\W` `\S` 는 각각 그 반대. 예: `'²'` 는 `\d` 가 아니지만 `\w` 다. `'\x1c'`, `'\xa0'` 는 `\s` 다.
- `\b` `\B` 의 '단어 문자'도 `\w` 와 같다.

## 규칙: 대소문자 무시 (`IGNORECASE`)

- 리터럴 문자, 문자 클래스, 역참조에 적용한다. `\d \w \s` 와 그 반대, `.`, 앵커는 영향 없다.
- 대상 문자 c 와 패턴 문자 x 는 `c.lower() == x.lower()` 이면 같다.
- 클래스: `c.lower()` 가 클래스에 적힌 문자들(범위는 그 안의 모든 문자)을 각각 `lower()` 한 것 중 하나와 같으면 클래스 항목에 맞는다. 부정은 그 뒤에 적용한다. 예: `[a-z]` 는 `'K'` 와 맞고 `[^a-z]` 는 `'K'` 와 맞지 않는다. `[Z-a]` 는 `'z'`, `'A'` 와도 맞는다.
- 역참조는 글자마다 `lower()` 로 비교한다: `(ab)\1` 은 `'abAB'` 와 맞는다.
- 시험은 ASCII 와 대소문자가 1:1 로 대응하는 몇몇 문자(é/É, ж/Ж 등)만 쓴다.

## 규칙: 앵커와 MULTILINE

- `^`: 문자열의 진짜 맨 앞(위치 0)에서만. `MULTILINE` 이면 모든 `\n` 바로 뒤에서도(문자열이 `\n` 으로 끝나면 끝 위치에서도).
- `$`: 끝, 그리고 **끝 바로 앞 글자가 `\n` 이면 그 `\n` 앞에서도**(`'a\n'` 에서 위치 1 과 2). `MULTILINE` 이면 모든 `\n` 앞과 끝.
- `\A`: 위치 0 에서만(MULTILINE 무관). `\Z`: 끝에서만(마지막 `\n` 앞은 아니다).
- `\b`: 한쪽은 단어 문자이고 다른 쪽은 아닌 위치(문자열 밖은 단어 문자가 아니다). `\B`: 그 반대.
- 여기서 "끝"은 endpos 다(아래 pos·endpos).

## 규칙: 매치 (역추적)

- 대안은 왼쪽 것부터 시도해 처음 성공하는 것을 고른다(가장 긴 것이 아니다): `a|ab` 를 `'ab'` 에서 search 하면 `'a'`. 뒤가 실패하면 역추적해 다음 대안을 시도한다.
- 탐욕 수량자는 가능한 한 많이, 게으른 수량자는 가능한 한 적게 반복하고, 뒤가 실패하면 역추적해 횟수를 바꾼다.
- **빈 반복**: 최소 횟수를 채운 뒤의 (선택적) 반복 한 번이 아무 글자도 소비하지 않으면, 그 반복은 인정하되(그 안의 캡처도 남는다) 더 반복하지 않고 수량자 다음으로 넘어간다(탐욕·게으름 모두). 최소 횟수를 채우는 반복은 비어도 계속한다. 예: `(a|)+` 를 `'aa'` 에 match 하면 그룹 1 은 위치 2 의 빈 문자열이고, `(?:()|a)*` 는 `'aa'` 에서 빈 문자열과 맞는다.
- `match(s, pos)`: pos 에서 시작하는 매치(끝까지일 필요는 없다). `fullmatch`: endpos 까지 정확히 맞아야 하고, 그렇게 되도록 역추적한다(`fullmatch("a|ab", "ab")` 는 매치). `search`: pos 부터 endpos 까지(endpos 위치 포함 — 빈 매치는 끝에서도 된다) 각 위치에서 차례로 시도해 가장 왼쪽 위치의 매치를 낸다.

## 규칙: 그룹

- 번호는 여는 괄호의 순서대로 1부터. 이름 그룹도 번호를 갖는다.
- 반복된 그룹의 값은 **마지막으로 성공한 반복**에서 잡은 값이다. 반복 안의 그룹이 나중 반복에서 맞지 않으면 **앞 반복에서 잡은 값이 그대로 남는다**: `(?:(a)|(b))+` 를 `'ab'` 에 맞추면 그룹은 `('a', 'b')`, `(a(b)?)+` 를 `'aba'` 에 맞추면 `('a', 'b')`.
- 역추적하면 그룹 값도 되돌아간다. 버려진 경로에서 잡은 값은 남지 않고, 그 전에 있던 값(앞 반복의 값 또는 없음)으로 돌아간다: `(?:(a)b|ac)` 를 `'ac'` 에 맞추면 그룹 1 은 None.
- 매치에 참여하지 않은 그룹의 값은 None, 위치는 -1.
- 그룹 이름은 `str.isidentifier()` 가 참이어야 하고(아니면 `error`), 비어 있으면 `error`, 같은 이름을 두 번 정의하면 `error`.

## 규칙: 역참조

- `\` 뒤의 숫자는 **최대 두 자리까지** 읽는다: `\11` 은 11번 그룹이다(1번 그룹 + 글자 `1` 이 아니다. 그렇게 쓰려면 `(?:\1)1`). 그 자리까지 **열린 그룹 수보다 큰 번호**면 `error`(뒤에 나오는 그룹을 가리켜도 `error`: `\2(a)(b)`). 아직 닫히지 않은 그룹(자신을 감싸는 그룹)을 가리켜도 `error`: `(a\1)`. `(?P=name)` 도 같고, 정의되지 않은 이름은 `error`.
- 가리키는 그룹이 그 시점에 값을 갖고 있지 않으면 역참조는 **실패**한다(빈 문자열과 맞지 않는다): `(a)?b\1` 은 `'b'` 와 맞지 않는다.
- IGNORECASE 면 대소문자를 무시하고 비교한다.

## 규칙: 전방·후방 탐색

- 너비 0 이다. 긍정 탐색 안에서 잡은 그룹 값은 남는다. 부정 탐색 안의 그룹은 값을 남기지 않는다.
- **탐색은 한 번 성공하면 다시 들어가 역추적하지 않는다**: `(?=(a+))a\1` 은 `'aaa'` 어디에서도 매치가 없다(전방 탐색이 `'aaa'` 를 잡은 뒤 더 짧은 길이를 시도하지 않는다).
- 후방 탐색의 내용은 고정 너비여야 한다: 가능한 모든 경로의 길이가 같아야 하고, 아니면 compile 이 `error`(`(?<=a+)`, `(?<=a|bc)`, `(?<=a{1,2})` 는 `error`. `(?<=ab|cd)`, `(?<=a{3})`, `(?<=(a)b)` 는 된다). 위치 i 의 후방 탐색은 위치 i − 너비에서 시작해 내용을 맞춰 본다. i − 너비 가 0 보다 작으면 긍정 탐색은 실패, 부정 탐색은 성공.

## 규칙: pos 와 endpos

- `Pattern` 의 `match` `search` `fullmatch` `findall` `finditer` 는 `(string, pos=0, endpos=None)` 를 받는다(None = 문자열 길이).
- 대상은 `string[:endpos]` 인 것처럼 다룬다: 매치는 endpos 를 넘지 못하고, `$` `\Z` `\b` `\B` 의 끝은 endpos, 전방 탐색도 endpos 너머를 보지 못한다.
- pos 는 "찾기 시작하는 위치"일 뿐 문자열을 자르지 않는다: `^` 와 `\A` 는 진짜 위치 0 에서만 맞으므로 pos > 0 이면 (MULTILINE 의 `\n` 바로 뒤가 아닌 한) 맞지 않고, `\b` `\B`·후방 탐색·MULTILINE `^` 는 pos 앞의 글자를 본다.
- pos 가 음수면 0, 길이보다 크면 길이로 본다. endpos 도 음수면 0, 길이보다 크면 길이(끝에서 거꾸로 세지 않는다). 그 결과 pos > endpos 이면 `search` 는 None, `findall` 은 `[]`, `finditer` 는 아무것도 내지 않는다.
- `Match.pos`·`Match.endpos` 는 이렇게 보정한 값이다.

## 규칙: findall · finditer · sub · subn · split 의 훑기

모두 같은 방법으로 왼쪽부터 겹치지 않는 매치를 차례로 찾는다(sub·subn·split 은 pos = 0, endpos = 길이):

1. 시작 위치 = pos.
2. 시작 위치부터 search 한다. 단 **바로 앞 매치가 빈 매치였다면, 시작 위치(= 그 빈 매치의 위치)에서는 빈 매치를 받아들이지 않는다** — 그 위치에서 역추적으로 비어 있지 않은 매치를 찾아보고, 없으면 다음 위치부터는 평소처럼(빈 매치도 허용) 찾는다.
3. 매치를 내고 시작 위치 = 그 매치의 끝으로 하고 2 로 간다. 매치가 없으면 끝.

그래서 빈 매치는 바로 앞의 비어 있지 않은 매치가 끝난 자리에서도 나온다: `sub("x*", "-", "abxd") == "-a-b--d-"`.

- `findall`: 그룹이 없으면 매치 문자열의 목록, 그룹이 하나면 그 그룹 값의 목록, 둘 이상이면 그룹 값 튜플의 목록. **참여하지 않은 그룹은 `''`**(None 아님).
- `finditer`: Match 의 반복자. 각 Match 의 pos·endpos 는 finditer 에 준 값(보정 후).
- `split(string, maxsplit=0)`: 매치 사이의 조각 목록. 패턴에 캡처 그룹이 있으면 매치마다 그 자리에 그룹 값들을 순서대로 끼운다(**참여하지 않은 그룹은 None**). 맨 앞·맨 뒤의 빈 조각도 남기고, 빈 매치로도 나눈다: `split(r"\b", "a b") == ['', 'a', ' ', 'b', '']`. maxsplit > 0 이면 최대 그 횟수만 나누고 나머지는 마지막 조각. **maxsplit < 0 이면 나누지 않는다**(`[string]`).
- `sub(repl, string, count=0)`: 매치를 repl 로 바꾼 문자열. count > 0 이면 앞에서부터 최대 count 개만. **count < 0 이면 아무것도 바꾸지 않는다.** `subn` 은 `(결과, 바꾼 개수)`. sub·subn 안에서 만드는 Match 의 pos 는 0, endpos 는 길이.

## 규칙: 치환 템플릿 (repl 이 문자열일 때. `Match.expand` 도 같다)

- `\g<name>`: 이름 그룹의 값. name 이 식별자인데 그런 이름의 그룹이 없으면 **`IndexError`**(`error` 아님).
- `\g<N>`: N 은 ASCII 숫자열. N 이 그룹 수보다 크면 `error`. `\g<0>` 은 매치 전체.
- `\N`: 패턴의 역참조처럼 숫자를 최대 두 자리까지 읽어 그룹 번호로 쓴다. 그룹 수보다 크면 `error`(`\10` 은 그룹이 10개 미만이면 `error`. 1번 뒤에 `0` 을 붙이려면 `\g<1>0`).
- `\n \t \r \f \v \a \b \\`: 해당 문자(`\b` 는 백스페이스 `\x08`, `\a` 는 `\x07`).
- 그 밖의 `\` + ASCII 영문자(예 `\q`, `\d`)는 `error`. `\` 뒤가 ASCII 영문자도 숫자도 아니면(예 `\-`, `\.`, `\&`, `\é`) **역슬래시까지 두 글자 그대로** 남는다. 템플릿이 `\` 하나로 끝나면 `error`. `\g` 뒤에 `<` 가 없거나, `>` 로 닫히지 않거나, 이름이 비었거나, 식별자도 ASCII 숫자열도 아니면(예 `\g<-1>`) `error`.
- 참여하지 않은 그룹은 빈 문자열로 바뀐다.
- **템플릿 오류는 매치가 없어도** sub·subn 을 부를 때 낸다(count < 0 이어도).
- 다루지 않는 것: 템플릿의 `\0`, 숫자 세 자리 8진수, `\x \u \U \N{...}`, 비 ASCII 숫자.
- repl 이 호출 가능하면 매치마다 `repl(match)` 를 부르고, 돌려준 문자열을 escape 처리 없이 **그대로** 넣는다.

## 오류

- `minire.error`: `Exception` 의 하위 클래스. 잘못된 패턴이면 `compile`(그리고 패턴을 받는 모듈 함수)이 낸다. 시험하는 경우: 짝이 맞지 않는 괄호(`(ab`, `ab)`, `a(b(c)`), nothing to repeat, multiple repeat, 수량자의 m > n, 잘못된 클래스(닫히지 않음, 잘못된 범위, 클래스 안의 잘못된 escape), 잘못된 escape, 패턴 끝의 `\`, 역참조 오류(없는 번호, 뒤에 나오는 그룹, 열린 그룹, 정의되지 않은 이름), 이름 그룹 오류(식별자 아님, 빈 이름, 중복), 고정 너비가 아닌 후방 탐색. 위에서 보통 문자·올바른 문법이라고 한 것은 오류를 내면 안 된다.
- `Match` 의 `group` `[]` `start` `end` `span` 에 없는 그룹 번호(음수 포함)나 이름을 주면 `IndexError`.

## API (`minire` 에서 import)

모듈:
- `compile(pattern, flags=0) -> Pattern`
- `match(pattern, string, flags=0)`, `search(pattern, string, flags=0)`, `fullmatch(pattern, string, flags=0)`: Match 또는 None.
- `findall(pattern, string, flags=0) -> list`, `finditer(pattern, string, flags=0)`.
- `sub(pattern, repl, string, count=0, flags=0) -> str`, `subn(pattern, repl, string, count=0, flags=0) -> tuple[str, int]`.
- `split(pattern, string, maxsplit=0, flags=0) -> list`.
- 모듈 함수는 `compile(pattern, flags)` 한 Pattern 의 같은 메서드와 같다.
- `escape(string) -> str`: 다음 문자 앞에만 `\` 를 붙인다: `( ) [ ] { } ? * + - | ^ $ \ . & ~ #`, 스페이스(`' '`), `\t` `\n` `\r` `\v` `\f`. 그 밖의 문자(영숫자, `_`, 다른 구두점, 비 ASCII)는 그대로.
- 플래그 상수: `IGNORECASE = I = 2`, `MULTILINE = M = 8`, `DOTALL = S = 16`(re 와 같은 값).
- `error`.

`Pattern`:
- `pattern`(원래 패턴 문자열), `groups`(캡처 그룹 수), `groupindex`(이름 → 번호 dict).
- `match(string, pos=0, endpos=None)`, `search(...)`, `fullmatch(...)`, `findall(string, pos=0, endpos=None)`, `finditer(string, pos=0, endpos=None)`, `sub(repl, string, count=0)`, `subn(repl, string, count=0)`, `split(string, maxsplit=0)`.

`Match`:
- `string`(원래 문자열 전체 — endpos 로 자르지 않음), `re`(이 매치를 만든 Pattern), `pos`, `endpos`.
- `group(*gs)`: 인자가 없으면 그룹 0(매치 전체), 하나면 그 값, 여럿이면 값의 튜플. 번호 또는 이름.
- `m[g]` 는 `m.group(g)`.
- `groups(default=None)`: 그룹 1..n 의 값 튜플(참여하지 않은 그룹은 default).
- `groupdict(default=None)`: 이름 → 값 dict(참여하지 않은 그룹은 default).
- `start(g=0)`, `end(g=0)`, `span(g=0)`: 번호 또는 이름. 참여하지 않은 그룹은 `-1`, `(-1, -1)`.
- `expand(template)`: 위 템플릿 규칙으로 만든 문자열.
- `lastindex`: **마지막으로 닫힌**(그 그룹의 오른쪽 괄호를 지난) 캡처 그룹의 번호, 없으면 None. 감싸는 그룹은 안쪽 그룹보다 늦게 닫히므로 `((a)b)` 와 `((ab))` 는 1, `(a)(b)` 는 2. 역추적으로 버려진 경로의 닫힘은 치지 않고(`(?:(a)(b)c|(a)bd)` 를 `'abd'` 에 맞추면 3), 긍정 전방·후방 탐색 안에서 닫힌 것은 치며, 부정 탐색 안에서 닫힌 것은 치지 않는다.
- `lastgroup`: lastindex 그룹의 이름. 그 그룹에 이름이 없거나 lastindex 가 None 이면 None.
