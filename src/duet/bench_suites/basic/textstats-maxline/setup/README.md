# textstats

`wc` 비슷하게 줄·단어·글자·바이트 수를 센다. 표준 라이브러리만 쓴다.

```bash
python -m textstats [-l] [-w] [-m] [-c] [FILE ...]
```

| 옵션 | 뜻 |
|---|---|
| `-l` | 줄 수 (`\n` 개수) |
| `-w` | 단어 수 (공백으로 구분) |
| `-m` | 글자 수 (UTF-8, 잘못된 바이트는 대체 문자 하나) |
| `-c` | 바이트 수 |

옵션이 없으면 `-l -w -c`. 열 순서는 항상 줄, 단어, 글자, 바이트. 파일이 2개 이상이면 마지막에 `total` 줄.

테스트: `python3 -m pytest -q`
